# Janus Studio 发布已知限制

- HTTP/HTTPS 查询停止只能终止客户端等待，无法保证服务端脚本已经中断；WS 是否支持服务端取消取决于服务器能力。
- GraphSON 整图导入不是事务性操作，中断不会自动回滚已经写入的数据；重新导入前应核对目标图并按需使用批量清空。
- ConfiguredGraphFactory 的关闭、Drop、实例清理和 Binding 传播依赖 JanusGraph 服务端配置及集群状态，不支持时入口会被兼容层阻止。
- JanusGraph 1.1 官方 Schema JSON 的专属字段在 1.0 环境中可能只能保留为人工审阅项，不能静默降级执行。
- 自动诊断是本地确定性规则分析，用于提供排查方向，不等同于完整的服务端根因证明。
- 没有平台签名和公证信息的产物属于测试包，不应作为正式发布包分发。
